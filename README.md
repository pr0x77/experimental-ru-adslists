# 🛡️ Experimental RU Adslists
Проект по созданию rule-листов для **Shadowrocket**, **Surge** и **Stash**.  
Фокус: русская реклама, трекеры, аналитика.

---

## 📋 Списки

| Название | Назначение | Действие |
| :--- | :--- | :--- |
| 🚫 RU Ads & Trackers | Реклама и трекеры РФ | REJECT |
| 🍏 Apple All | Инфраструктура Apple | DIRECT / PROXY |
| 🚫 RU uBlock Origin | RU | REJECT |
